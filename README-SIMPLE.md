# نسخه ساده پروژه رتبه بندی صندوق های سرمایه گذاری هند

این نسخه برای یادگیری و دفاع دانشگاهی آماده شده است. ساختار پروژه چهار فایل اصلی دارد و کدها تا حد ممکن ساده و فارسی توضیح داده شده اند.

## نصب و اجرا

```bash
pip install -r requirements-simple.txt
streamlit run simple_app.py
```

## فایل های پروژه

- `simple_data.py`: دریافت فهرست صندوق ها، فیلتر صندوق های واجد شرایط و دریافت NAV.
- `simple_metrics.py`: محاسبه بازدهی، نوسان، افت سرمایه، شارپ و سورتینو؛ دریافت آلفا و بتا.
- `simple_ranking.py`: تبدیل شاخص ها به امتیاز و رتبه بندی برای چهار پروفایل ریسک.
- `simple_app.py`: پرسش نامه ریسک، داشبورد، نمودارها و جدول مقایسه.

## محدوده انتخاب صندوق ها

برنامه صندوق های فعال، Direct Growth، از نوع Open Ended و با حداقل سه سال سابقه را در شش گروه زیر فیلتر می کند:

- Large Cap
- Mid Cap
- Small Cap
- Flexi Cap
- Multi Cap
- Focused

برای محدود ماندن زمان دریافت تاریخچه NAV، در نسخه فعلی حداکثر پنج صندوق از هر گروه وارد بررسی عمیق می شوند (حداکثر ۳۰ صندوق). این پنج مورد بر اساس ترتیب دریافتی منبع داده انتخاب می شوند؛ بنابراین رتبه بندی نهایی فقط بین صندوق های بررسی شده معتبر است و نباید آن را رتبه بندی تمام صندوق های بازار معرفی کرد.

## شاخص های مالی

- بازدهی یک هفته، یک ماه، سه ماه، شش ماه، یک سال و سه سال
- نوسان پذیری سالانه بر اساس انحراف معیار بازدهی روزانه و ۲۵۲ روز معاملاتی
- حداکثر افت سرمایه از بالاترین NAV قبلی
- نسبت شارپ با فرض نرخ بدون ریسک صفر
- نسبت سورتینو با محاسبه ریسک نزولی نسبت به بازده هدف صفر
- آلفا و بتای سه ساله از Charlie Alpha API

آلفا و بتا از API عمومی Charlie Alpha دریافت می شوند. این سرویس شاخص مرجع هر صندوق را خودش مشخص می کند. آلفا در پاسخ سرویس به درصد سالانه است و در برنامه به عدد اعشاری تبدیل می شود. بتا در جدول نمایش داده می شود، اما مستقیماً وارد امتیاز نهایی نمی شود؛ چون بتای بالاتر همیشه بهتر یا بدتر نیست.

## روش رتبه بندی

ابتدا هر شاخص به امتیاز صفر تا صد تبدیل می شود. در بازدهی و کیفیت عملکرد، مقدار بالاتر امتیاز بیشتری می گیرد؛ در نوسان پذیری، مقدار کمتر امتیاز بیشتری می گیرد. سپس امتیاز بازدهی، ریسک و کیفیت با وزن های متفاوت ترکیب می شوند:

| پروفایل | بازدهی | ریسک | کیفیت |
|---|---:|---:|---:|
| Conservative | ۲۰٪ | ۵۰٪ | ۳۰٪ |
| Moderate | ۴۰٪ | ۳۰٪ | ۳۰٪ |
| Growth | ۵۵٪ | ۲۰٪ | ۲۵٪ |
| Aggressive | ۶۵٪ | ۱۰٪ | ۲۵٪ |

اگر یک بخش به دلیل نبود داده قابل محاسبه نباشد، وزن آن بین بخش های دارای داده تقسیم می شود. به این ترتیب نبود یک شاخص باعث خالی شدن امتیاز کل صندوق نمی شود.

## منابع داده

- فهرست صندوق ها و NAV: API شرکت Tigzig؛ بازنشر داده های صندوق های هند و نه منبع رسمی AMFI.
- آلفا و بتا: Charlie Alpha API، با افق سه ساله.
- مستندات سرویس آلفا و بتا: https://api.charliealpha.in/

## محدودیت ها

این برنامه یک ابزار آموزشی برای مقایسه صندوق هاست، نه توصیه خرید یا فروش. رتبه بندی به کیفیت و پوشش داده های منبع وابسته است. پیش از نتیجه گیری باید تعداد صندوق های بررسی شده، پوشش NAV و تاریخ به روزرسانی داده ها گزارش شوند.
