# نسخه ساده پروژه رتبه بندی صندوق های سرمایه گذاری

این نسخه برای یادگیری و ارائه دانشگاهی نوشته شده است. کدها عمداً ساده هستند و توضیحات فارسی دارند.

## ۱. نصب برنامه

ابتدا Python را نصب کنید. سپس در ترمینال وارد پوشه پروژه شوید و این دستورها را اجرا کنید:

```bash
pip install -r requirements-simple.txt
```

## ۲. اجرای برنامه

```bash
streamlit run simple_app.py
```

## ۳. اطلاعات مورد استفاده

اطلاعات صندوق ها و NAV از API شرکت Tigzig دریافت می شود. این API داده های صندوق های سرمایه گذاری هند را بازنشر می کند و منبع رسمی AMFI نیست.

برنامه صندوق های فعال، Direct Growth و دارای حداقل سه سال سابقه را انتخاب می کند. سپس گروه صندوق انتخاب شده را بررسی می کند.

## ۴. شاخص های محاسبه شده

- بازدهی یک هفته، یک ماه، سه ماه، شش ماه، یک سال و سه سال
- نوسان پذیری سالانه
- حداکثر افت سرمایه
- نسبت شارپ
- نسبت سورتینو
- آلفا و بتا، در صورت دسترسی به داده معتبر شاخص مرجع

## ۵. دریافت خودکار شاخص بازار و محاسبه آلفا و بتا

برنامه شاخص مرجع را بر اساس گروه صندوق انتخاب می کند و تلاش می کند اطلاعات روزانه TRI را مستقیماً از سایت Nifty Indices دریافت کند. بنابراین در حالت عادی نیازی به بارگذاری فایل شاخص نیست. با این حال، سایت ممکن است درخواست های بعضی سرورها از جمله محیط های ابری GitHub Actions را مسدود کند. اگر دریافت شاخص ممکن نباشد، برنامه رتبه بندی را با سایر شاخص ها ادامه می دهد و آلفا و بتا را خالی نمایش می دهد؛ این مقادیر حدس زده یا جایگزین نمی شوند.

- Large Cap: شاخص NIFTY 50 TRI
- Mid Cap: شاخص NIFTY MIDCAP 150 TRI
- Small Cap: شاخص NIFTY SMALLCAP 250 TRI
- Flexi Cap، Multi Cap و Focused: شاخص NIFTY 500 TRI

TRI بازده قیمت و سود نقدی سرمایه گذاری شده را در نظر می گیرد. برای محاسبه آلفا و بتا، فقط تاریخ هایی استفاده می شوند که هم NAV صندوق و هم شاخص بازار برای آن ها داده دارند.

توجه: در این نسخه برای ساده نگه داشتن پروژه، شاخص مرجع بر اساس گروه صندوق انتخاب می شود. در واقعیت ممکن است بعضی صندوق ها benchmark اختصاصی متفاوتی داشته باشند. همچنین دریافت اطلاعات از صفحه تاریخی Nifty Indices به ساختار فعلی سایت و محدودیت های دسترسی آن وابسته است. برای محاسبه معتبر آلفا و بتا باید داده TRI واقعی و تاریخ های مشترک کافی در دسترس باشد.

## ۶. روش رتبه بندی

ابتدا هر شاخص به امتیاز صفر تا صد تبدیل می شود. سپس امتیاز بازدهی، ریسک و کیفیت با وزن های متفاوت برای چهار پروفایل ترکیب می شوند.

بتا در جدول نشان داده می شود اما مستقیم وارد امتیاز نهایی نمی شود؛ چون بتای بالاتر همیشه بهتر یا بدتر نیست.

## ۷. نکته مهم

این نسخه آموزشی است. پیش از نتیجه گیری نهایی باید نام ستون های دسته بندی API، کیفیت داده های NAV، فایل شاخص مرجع و تطبیق تاریخ ها بررسی شوند. بازدهی های کوتاه مدت به تنهایی معیار مناسبی برای تصمیم سرمایه گذاری نیستند.

این پروژه توصیه سرمایه گذاری نیست.
