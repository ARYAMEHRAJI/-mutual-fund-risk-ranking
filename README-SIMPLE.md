# نسخه ساده پروژه رتبه بندی صندوق های سرمایه گذاری

این نسخه برای یادگیری و ارائه دانشگاهی نوشته شده است. کدها عمداً ساده هستند و توضیحات فارسی دارند.

## ۱. نصب برنامه

ابتدا Python را نصب کنید. سپس در ترمینال وارد پوشه پروژه شوید و این دستورها را اجرا کنید:

```bash
pip install -r requirements-simple.txt
```

## ۲. اجرای برنامه

```bash
streamlit run simple_app.py
```

## ۳. اطلاعات مورد استفاده

اطلاعات صندوق ها و NAV از API شرکت Tigzig دریافت می شود. این API داده های صندوق های سرمایه گذاری هند را بازنشر می کند و منبع رسمی AMFI نیست.

برنامه صندوق های فعال، Direct Growth و دارای حداقل سه سال سابقه را انتخاب می کند. سپس گروه صندوق انتخاب شده را بررسی می کند.

## ۴. شاخص های محاسبه شده

- بازدهی یک هفته، یک ماه، سه ماه، شش ماه، یک سال و سه سال
- نوسان پذیری سالانه
- حداکثر افت سرمایه
- نسبت شارپ
- نسبت سورتینو
- آلفا و بتای سه ساله، از API مستقل Charlie Alpha

## ۵. منابع داده و محاسبه آلفا و بتا

اطلاعات فهرست صندوق ها و NAV از API شرکت Tigzig دریافت می شود. این سرویس داده های صندوق های سرمایه گذاری هند را بازنشر می کند و منبع رسمی AMFI نیست.

برای آلفا و بتا از API عمومی Charlie Alpha استفاده می شود:

- نشانی API: https://api.charliealpha.in/v1/mf/metrics/{scheme_code}
- مستندات: https://api.charliealpha.in/
- دریافت بدون API Key و با درخواست GET
- ورودی: کد شش رقمی AMFI هر صندوق
- خروجی: آلفا و بتا در افق های ۱، ۳، ۵ و ۱۰ ساله
- در این پروژه افق سه ساله استفاده می شود.
- شاخص مرجع هر صندوق از اطلاعات همان سرویس گرفته می شود؛ بنابراین محاسبه آلفا و بتا به دریافت مستقیم Nifty یا Yahoo Finance وابسته نیست.

مقدار آلفا به صورت درصد سالانه از API دریافت و برای استفاده در مدل به عدد اعشاری تبدیل می شود. بتا در جدول نمایش داده می شود اما مستقیم وارد امتیاز نهایی نمی شود.

برای اینکه زمان دریافت NAV خیلی طولانی نشود، حداکثر پنج صندوق از هر یک از شش گروه (Large Cap، Mid Cap، Small Cap، Flexi Cap، Multi Cap و Focused) وارد بررسی عمیق می شوند؛ یعنی حداکثر ۳۰ صندوق. سپس پنج صندوق برتر بر اساس پروفایل ریسک کاربر انتخاب می شوند. داشبورد تعداد کل صندوق های دریافت شده، تعداد واجد شرایط، تعداد دارای NAV و تعداد بررسی شده را جداگانه نمایش می دهد.

## ۶. روش رتبه بندی

ابتدا هر شاخص به امتیاز صفر تا صد تبدیل می شود. سپس امتیاز بازدهی، ریسک و کیفیت با وزن های متفاوت برای چهار پروفایل ترکیب می شوند.

بتا در جدول نشان داده می شود اما مستقیم وارد امتیاز نهایی نمی شود؛ چون بتای بالاتر همیشه بهتر یا بدتر نیست.

## ۷. نکته مهم

این نسخه آموزشی است. پیش از نتیجه گیری نهایی باید نام ستون های دسته بندی API، کیفیت داده های NAV، فایل شاخص مرجع و تطبیق تاریخ ها بررسی شوند. بازدهی های کوتاه مدت به تنهایی معیار مناسبی برای تصمیم سرمایه گذاری نیستند.

این پروژه توصیه سرمایه گذاری نیست.
