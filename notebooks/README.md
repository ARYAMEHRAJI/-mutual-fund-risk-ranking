# Research notebook

The original working notebook is the research source of truth for the exploratory work completed in Colab. Its logic has been separated into reusable modules under src/fundrank.

The notebook file itself is not yet included in this repository. Add the final Colab export here as research.ipynb after downloading it from Colab. Keep the notebook as a reproducibility record; production execution should use scripts/run_pipeline.py rather than running notebook cells in sequence.
